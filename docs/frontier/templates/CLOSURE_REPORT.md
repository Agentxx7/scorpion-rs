# Closure Report Template

```markdown
# <FRONTIER_ID> — Closure Report

- closure commit SHA: <SHA>
- exact commit message: <message>
- push result: <result>
- HEAD/origin/main equality: <SHAs, equal/not-equal>
- worktree status: <clean/dirty>
- index status: <clean/dirty>
- git diff --check result: <PASS/FAIL>
- git diff --cached --check result: <PASS/FAIL>

Closure requires every line above to hold. Any failure = not closed.
```
